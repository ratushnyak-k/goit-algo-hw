## Висновки (Завдання 3)

Емпіричне порівняння трьох алгоритмів показало наступне:

1. **Timsort (вбудований sorted/sort)** - показав найкращу ефективність
   на всіх типах вхідних даних. Він поєднує сортування злиттям
   та сортування вставками, що робить його особливо швидким
   на частково впорядкованих масивах.

2. **Сортування злиттям** - стабільно працює зі складністю O(n log n),
   що робить його ефективнішим за сортування вставками
   на великих наборах даних.

3. **Сортування вставками** - ефективне лише на малих
   або майже відсортованих масивах (складність O(n²)).
   На великих випадкових масивах значно поступається
   іншим алгоритмам.

**Чому програмісти використовують вбудовані засоби сортування?**

Timsort розроблений спеціально для реального світу, де дані
часто вже частково впорядковані. Саме через його
ефективність і надійність Python використовує його
за замовчуванням - немає сенсу писати власний алгоритм,
якщо вбудований уже оптимізований.
