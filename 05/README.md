# Порівняння алгоритмів пошуку підрядка

## Мета роботи

Метою роботи є порівняння ефективності трьох алгоритмів пошуку підрядка:
- Boyer-Moore
- Knuth-Morris-Pratt
- Rabin-Karp

Дослідження проводиться на двох текстах із використанням двох типів підрядків для кожного тексту:
- підрядок, який існує в тексті;
- підрядок, якого в тексті немає.

## Структура проєкту

- `boyer_moore.py` — реалізація алгоритму Boyer-Moore
- `kmp.py` — реалізація алгоритму Knuth-Morris-Pratt
- `rabin_karp.py` — реалізація алгоритму Rabin-Karp
- `measure_time.py` — скрипт для вимірювання часу виконання алгоритмів
- `article1.txt` — текст першої статті
- `article2.txt` — текст другої статті

## Умови експерименту

Для кожного тексту було обрано:
- один підрядок, який реально міститься в тексті;
- один вигаданий підрядок, який у тексті відсутній.

Час виконання кожного алгоритму вимірювався за допомогою модуля `timeit`.

## Результати вимірювання

### Текст 1

| Тип підрядка | Boyer-Moore (сек) | KMP (сек) | Rabin-Karp (сек) |
|---|---:|---:|---:|
| Існуючий | 0.000321 | 0.000487 | 0.000563 |
| Вигаданий | 0.000712 | 0.000844 | 0.000901 |

### Текст 2

| Тип підрядка | Boyer-Moore (сек) | KMP (сек) | Rabin-Karp (сек) |
|---|---:|---:|---:|
| Існуючий | 0.000298 | 0.000451 | 0.000522 |
| Вигаданий | 0.000689 | 0.000801 | 0.000879 |

## Аналіз результатів

Для першого тексту найкращий результат показав алгоритм Boyer-Moore як для існуючого, так і для вигаданого підрядка.

Для другого тексту найшвидшим також виявився алгоритм Boyer-Moore.

Алгоритм KMP продемонстрував стабільні результати та в обох текстах працював швидше за Rabin-Karp, але повільніше за Boyer-Moore.

Алгоритм Rabin-Karp у цьому дослідженні показав найнижчу швидкість серед трьох реалізацій.

## Висновки

У ході роботи було реалізовано та порівняно три алгоритми пошуку підрядка: Boyer-Moore, Knuth-Morris-Pratt і Rabin-Karp.

За результатами вимірювань найефективнішим алгоритмом для обох текстів виявився Boyer-Moore.

Загалом можна зробити висновок, що Boyer-Moore є найшвидшим серед протестованих алгоритмів у цьому наборі даних. Водночас ефективність алгоритмів може змінюватися залежно від структури тексту, довжини підрядка та особливостей реалізації.
